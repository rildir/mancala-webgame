# Mancala Oyunu

![image](https://github.com/user-attachments/assets/eecfe6e2-1139-4c40-b92c-c5bea124657a)

## 🎲 Proje Hakkında

Bu proje, klasik **Mancala** oyununu modern ve kullanıcı dostu bir arayüzle web ortamına taşıyan bir uygulamadır, projeyi yeğenimin doğum günü için yaptım. Tamamen vanilla JavaScript, HTML ve CSS kullanılarak geliştirdim. 

## 🚀 Özellikler

- **Gerçek Mancala Kuralları:** Oyun, geleneksel Mancala kurallarına uygun olarak oynanır.
- **Kullanıcı Dostu Arayüz:** Modern ve sade bir tasarım, kolay anlaşılır oyun alanı.
- **Geri Alma (Undo):** Son hamleyi geri alabilme özelliği.
- **Yeniden Başlat:** Oyunu tek tıkla sıfırlama.
- **Oyun Kuralları:** Bilgilendirici modal ile oyun kurallarına hızlı erişim.
- **Ses Efekti:** Arka plan müziği ve ses aç/kapat butonu.
- **Avatarlar:** Yeğenlerim için özel avatar görselleri.

## 🛠️ Kullanılan Teknolojiler

- **HTML5**
- **CSS3** 
- **Vanilla JavaScript (ES6+)**
- **Google Fonts**
- **Phosphor Icons**

## ⚡ Kurulum ve Çalıştırma

1. **Projeyi Klonlayın:**
   ```sh
   git clone https://github.com/rildir/mancala-webgame
   cd mancala-webgame
   ```

2. **Projeyi Başlatın:**
   - Sadece `index.html` dosyasını bir tarayıcıda açmanız yeterlidir.
   - Ekstra bir bağımlılık veya kurulum gerektirmez.
